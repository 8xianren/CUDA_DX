## 构建与运行

下面命令从**仓库根目录**执行。普通 CUDA 编译统一走 sandbox 构建器，它加载 VS2022 环境并面向 `sm_120`；可执行文件留在本课源码旁。按表中库参数编译其它同组文件。

```powershell
& learning/sandbox/build.ps1 learning/sandbox/cuda/08-02-grid-sync/grid_sync.cu -NoRun
& learning/sandbox/cuda/08-02-grid-sync/grid_sync.exe
```
