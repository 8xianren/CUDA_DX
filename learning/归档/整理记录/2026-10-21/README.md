## 后续维护

从仓库根运行：

```powershell
python learning/tools/catalog.py --write
```

这会更新资料导航与 JSON 清单，并输出本地断链和缺失课程 README。新增课程仍遵守 [sandbox 目录约定](../../../sandbox/README.md)，结果写入本课 `results/`，讲义保留 `learning/笔记/<线路>/` 并双向链接。需要重新验证迁移程序时，运行 `learning/tools/verify_organization.ps1`；该脚本会编译和执行 GPU 程序。
