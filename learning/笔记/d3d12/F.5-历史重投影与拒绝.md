# F.5 教学 TAA：重投影、拒绝与邻域约束

[F 主线程序](../../sandbox/d3d12/aa-reconstruction/README.md) · [输入契约](F.4-时域重建输入契约.md) · [下一节空间超分](F.6-动态分辨率与空间超分.md)

目标是能主动复现 ghosting，并逐项解释重投影、深度拒绝、颜色约束解决什么问题。实现入口为 `shaders/post.hlsl:81` 的 `TaaCS`；CPU 参考是 `audit_temporal.py:temporal`。两边分别计算，不把截图“看着差不多”当作数值验证。

## 1. 先建立最简单的平均，再指出假设

假设每帧对同一个静止信号得到一个不同样本，可以用递推平均降低波动：

```text
result = (1 − w) × current + w × history
```

展开后，历史样本权重按 `w^k` 衰减；这是指数移动平均，不是“无限增加真实 spp”。如果输入信号变了、历史取错表面，平均只会把错误延续更久。比如旧白色角色离开后背景变黑，w=0.9 时第一个错误结果仍为 0.9，10 帧后仍约为 0.349。拖影来自错误历史或响应过慢，而不是一个必须忍受的抽象“时域副作用”。

游戏类比是合并前几帧的侦察报告：先把报告定位到同一地点，再判断该地点是否换了主人，最后限制可疑报告的影响。直接平均未经验证的历史，不是完成了 TAA。

## 2. 为什么先拒绝，再采样历史

前节已经推得 `previousUV=currentUV+motion+previousJitter-currentJitter`。本节按顺序执行：

1. 全局 `HistoryValid` 为 false：直接输出当前颜色，不读取旧颜色。
2. previousUV 非有限数或超出 `[0,1)`：拒绝。linear-clamp sampler 不会自动给出“没有历史”，只会复制边界像素；所以越界必须在采样前处理。
3. 从旧深度纹理取对应点，比较旧图真正可见的深度与当前表面的预期旧深度。
4. 通过以上检查，才读取旧颜色；若颜色非有限数仍拒绝。

深度容差使用：

```text
abs(actualPreviousZ − expectedPreviousZ)
    <= max(0.001, abs(expectedPreviousZ) × relativeThreshold)
```

绝对项防止极近距离容差趋零，相对项让远距离的数值和几何误差有合理空间。0.02 是教学默认，不是普适正确值。深度取最近的离散 texel，不对前景与背景的深度做双线性平均，因为平均出来的深度可能根本没有对应表面。旧颜色仍做双线性，这会在边缘混入其他表面；本课的邻域约束用于减轻这种污染，不能宣称彻底解决。

遮挡显露是关键反例：本帧看到深处背景，沿 motion 找到的上帧位置却由近处角色占据。两个深度不同就要拒绝。反过来，同深度但材质、光照或透明层发生变化，深度拒绝无法看出来，必须继续做颜色限制。

## 3. 从颜色可接受范围推导 clamp

假设当前像素周围 3×3 给出了这一区域当前可能出现的颜色范围，分别求每通道 min/max，得到一个颜色轴对齐包围盒。将历史颜色限制在盒内，再参与平均。这个假设会引入偏差：某一帧没采到的真实细亮线也可能被认为“不可信”，所以 clamp 与稳定性之间存在权衡。

RGB 盒可能较松。把 RGB 转成近似亮度和色度的 YCoCg，有时可以让亮度变化与色度变化分开约束：

```text
Y  = R/4 + G/2 + B/4
Co = R/2 − B/2
Cg = −R/4 + G/2 − B/4

R = Y + Co − Cg
G = Y + Cg
B = Y − Co − Cg
```

这不是“YCoCg 总比 RGB 正确”的定理。它换了包围盒的方向，效果取决于局部颜色分布。本课实现逐通道 **clamp**，没有把它包装成 Karis 的线段 clipping、方差裁剪或完整 UE TAA。生产实现通常还会处理历史重建核、锐化、抗闪烁、速度膨胀、曝光与多层透明等问题。

Reactive Mask 的值 r 在 [0,1]，有效历史权重设为 `w_eff=w×(1−r)`。r=1 的透明响应像素完全用当前帧；这是牺牲该位置的时域平滑，换取对变化更快的反应。它不是物理材质不透明度：两者可以相关，但职责不同。

## 4. 开关、诊断与所有权

`flags` 的位为：1 历史有效，2 重投影，4 深度拒绝，8 邻域 clamp，16 YCoCg，32 motion 已含 jitter。默认正常帧为 31，首帧为 30。消融实验（ablation）是只关闭某一机制、保持其他条件不变，以观察该机制的因果作用。

|消融|flags 示例|预期现象|
|---|---|---|
|关闭重投影|29|运动历史停在错误屏幕地址|
|关闭深度拒绝|27|遮挡显露更容易借用前景颜色|
|关闭 clamp|23|同深度的颜色变化容易持续拖影|
|RGB clamp|15|与 YCoCg 比较色偏和约束范围|
|完整当前帧重置|30|不读取历史；结果等于当前帧|

oracle 为了使每种错误明显，部分案例同时关闭其他机制作为隔离条件；例如 `no_depth` 使用 flags=3，让 clamp 不掩盖深度拒绝的贡献。真实场景单因素消融和人工构造的隔离 oracle 是两种不同实验，报告必须分别说明。

u1 诊断输出为 `(是否使用历史,历史clamp改变量的长度,运动像素长度,拒绝原因)`。原因 1=全局重置、2=越界、3=深度、4=非有限旧颜色、5=完全 reactive。它让“看见拖影”进一步变成“哪个像素接受了不该接受的历史”的可检验问题。

双缓冲历史应按帧交换角色：上一帧 A 为 t1，本帧 B 为 u0；完成后 B 才成为下帧历史。深度也要与对应历史颜色来自同一帧。CPU 不能在前帧 GPU 尚在读取 A 时覆写 A；Fence 控制存储复用，HistoryValid 控制语义复用，二者不能互相代替。

这两张 A/B 是 **jittered history 格点**。最终还运行独立 `UnjitterCS`：若 `TaaCS` 的结果为 `Fj(u)=F(u−j)`，则固定输出格点应取 `Fj(u+j)`。Unjitter 读 B 写第三张输出纹理，再交给捕获/显示；第三张纹理不成为下一帧 history。其资源状态、UAV 依赖和 Fence 与其他后处理 pass 相同，timestamp 必须覆盖它。这样才可和未抖动的 No AA、MSAA、4×参考图逐像素比较。

边缘采用 linear clamp，所以抖动平移需要画面外信息时复制边界值，并没有凭空补出新视野。多一次双线性重采样还可能软化细节；生产 TAA 更常把固定格点重建与历史融合合成一个流程。本课独立拆开，便于验证两种网格，不能声称与生产历史重建核等价。

可选 `SharpenCS` 必须是后续独立 pass，读已完成的 TAA 图再写另一纹理；不能在 TAA 内直接读取邻线程刚写出的 u0。它作为已编译的扩展入口保留，**本次质量序列没有启用额外锐化**，不把锐化后的观感混入 TAA 对照。锐化只是重分配已有频率，不能恢复根本不存在的真实细节，也会放大噪声和振铃。

## 5. 独立验收方法

从仓库根目录执行：

```powershell
python learning/sandbox/d3d12/aa-reconstruction/audit_temporal.py --emit-fixtures
& learning/sandbox/d3d12/aa-reconstruction/build/Release/f_lessons.exe oracle
# 上述 GPU 程序生成各目录 output.f32 与 diagnostic.f32，然后独立比较。
python learning/sandbox/d3d12/aa-reconstruction/audit_temporal.py `
  --gpu-oracle-root learning/sandbox/d3d12/aa-reconstruction/results/f5/oracle-input
```

输入包括 reset、重投影与关闭重投影、RGB/YCoCg clamp、遮挡显露与关闭深度、reactive、jitter 是否已包含的两种合同，另有完全越界与“当前深度 3、预期旧深度 4、实际旧深度 4”的反例。reset 的旧颜色特意填 NaN，检验首帧不会受无效旧值污染。Unjitter 另有正/负 jitter、边界和零位移 identity 四例；这四例不改变原历史 oracle 的语义。每个目录有 `entry.txt`、64 字节 `constants.bin`、RGBA float32 输入。C++ GPU 执行结果与独立 NumPy 参考比较；浮点纹理 oracle 容差为 2×10⁻⁴。实际场景使用 RGBA16F，须单独考虑量化，不能套用相同的精度承诺。

CPU 自检已经证明：全黑当前帧加全白历史、w=0.9 时，关闭 clamp 得到 0.9，开启 clamp 得到 0；预期旧深度为 4、实际旧深度为 2 时，开启深度拒绝得到 0，关闭得到 0.9。这些数字是解析构造案例，不是声称真实动画场景的 MSE。

2026-10-22 在 RTX 5070 实际执行 **22 个 GPU oracle**（12 个 TAA、6 个空间缩放、4 个 Unjitter）：全部通过，D3D12 `debug_warning_error=0`，Fence 为 157/157。TAA 最大颜色误差为 **5.96046×10⁻⁸**，诊断最大误差 **3.47240×10⁻⁷**；reset、越界、深度显露和预期旧深度案例均为零颜色误差。Unjitter 的非零正负偏移和边界案例最大误差 **2.98023×10⁻⁸**，identity 为零。可检查 [GPU oracle 报告](../../sandbox/d3d12/aa-reconstruction/results/f5/gpu-oracle.json)。真实动态序列与误差另记录在 F.10 统一报告；构造案例通过不能替代动态画面质量评价。缺少 GPU 输出时脚本会失败并报告 missing，不会用 CPU 结果替代。

同日真实 640×360 动态场景的 120 帧 TAA 序列累计有 **26,551,986 次像素历史使用**和 **415,243 次深度拒绝**。首帧和 frame 60 Camera Cut 的历史接受数均为 0，下一帧重新建立历史。这里统计的是“像素×帧”的事件数量，不是独立像素或独立光线样本。记录见 [TAA summary](../../sandbox/d3d12/aa-reconstruction/results/f10/sequences/taa/summary.json) 与 [逐帧计数](../../sandbox/d3d12/aa-reconstruction/results/f10/sequences/taa/frames.csv)；是否还有拖影及其强度，要继续看有参考图的误差、显露区域与消融结果，不能仅凭拒绝次数大就宣称画质更好。

对 frame 30/59/60/119 的实际图像检查发现：Cut 帧没有继承上一帧角色位置的残影；但完整教学 TAA 在正常累计帧明显软化棋盘和细线，关闭重投影的静态背景反而可能更锐。原因是本实现沿 jittered 历史反复双线性重采样，最终再 Unjitter 又有一次滤波；每次坐标正确不代表整个重建核不会累积模糊。关闭 clamp 时移动边缘的软残留也更宽。应把这些图像现象与 F.10 的静态/显露/动态 ROI 指标一起看，不能用“开关全开”自动推定所有质量指标最优。这正是后续需要固定格点高质量重建核、历史锐度控制等生产机制的原因；本课完成的是可解释、可消融的教学基线。

最终 120 帧统计把这一现象定量化。下表的 ROI 均由共同 No AA guide 产生，各模式使用同一批像素；显露区域累计 **77,413 个像素×帧**（232,239 个 RGB 分量），不是人为挑选的某个截图。显示域误差使用固定曝光、Reinhard、sRGB；参考为同帧 4× 每轴光栅化再 4×4 box 的有限采样图。

|TAA 模式|全图显示域 MAE|静态背景 MAE|移动遮挡物 MAE|显露区域 MAE|参考误差相邻帧变化 RMS|
|---|---:|---:|---:|---:|---:|
|完整教学实现|0.040230|0.103277|0.002582|0.054282|0.018952|
|关闭重投影|0.023024|0.058722|0.001033|0.049239|0.044766|
|关闭深度拒绝|0.041968|0.105704|0.002657|0.174102|0.018332|
|关闭颜色 clamp|0.041840|0.105057|0.003812|0.057200|0.018880|

这组消融需要分别解读。关闭深度拒绝使显露 MAE 约为完整实现的 **3.21 倍**，比全图平均数更直接地揭示错误表面历史的污染；关闭 clamp 则使移动遮挡物 ROI 误差增加。关闭重投影虽降低全图与静态背景误差，但参考误差的相邻帧变化 RMS 从 0.018952 增至 0.044766，约 **2.36 倍**；它少了一部分反复重采样的模糊，却没有正确的跨帧表面对应，不能由单帧更锐推定运动表现更好。这个 RMS 在屏幕坐标求误差变化并排除 cut，仍不是运动补偿后的感知闪烁指标。

完整 TAA 的全图 MAE 0.040230 高于同尺寸 No AA 的 0.009803，必须承认这个基线在本场景明显过软；合同正确、oracle 通过与观感优良是三个不同的判断。Camera Cut 帧的四种 TAA MAE 都是 0.019448，完整 TAA 后续 frame 61/62/63 分别为 0.027586/0.030636/0.036841，展示历史重新累计后的误差变化，而非“重置以后误差必须单调下降”。透明粒子 ROI 的完整 TAA MAE 为 0.012678，但该区域由单个 guide 深度标记近似，无法代表透明多层的全部覆盖。原始统计与逐帧曲线见 [质量 summary](../../sandbox/d3d12/aa-reconstruction/results/f10/quality/summary.json)、[误差曲线](../../sandbox/d3d12/aa-reconstruction/results/f10/quality/error-over-time.svg)；它们支持本教学实现的局部机制分析，不用于品牌排名。

最终F.10把显露区域单独统计后，完整TAA / 关闭深度拒绝的显示MAE为 **0.054282 / 0.174102**，约3.21倍；全帧却只是0.040230 / 0.041968。ROI证明深度拒绝保护了新显露表面，也解释为何全屏平均会掩盖局部严重拖影。关闭重投影时全局MAE为0.023024，但误差时域变化升至0.044766，完整TAA为0.018952；锐度与时域稳定性需要分别评估。数据与图见[F10](F.10-固定序列质量与性能评测.md)。

## 6. 自测题与答案

**Camera Cut 后可以用历史权重 0 来代替不读取历史吗？** 数学上有限值乘零看似无影响，但无效资源、NaN 或已经释放的描述符不是合法可读数据。本课先分支拒绝，根本不采样。

**clamp 开得越严格越好吗？** 不。它能压住拖影，也会压掉当前邻域未采到的细节，降低跨帧子像素积累的价值。

**TAA 是否等价于把更多路径追踪样本相加？** 不等价。TAA 包含重建、过滤、拒绝和有偏约束；不会凭空产生新的独立光线路径样本。H 的动态降噪与本节共享历史有效性机制，但估计目标、噪声分布与评价指标仍需区分。
