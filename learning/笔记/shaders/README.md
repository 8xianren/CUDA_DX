# 图形着色器补充课索引

[返回笔记总目录](../README.md) · [D3D12 主线](../d3d12/README.md) · [粒子主线](../particles/README.md)

本目录有 5 篇补充讲义。按需穿插在 D3D12 / 粒子课程中，沿用对应课程程序，不建立重复的“着色器工程”。建议先看 API 与资源使用场景，再用这些讲义补语言和数学细节。

1. [补充 1：HLSL 与 GLSL 基础](图形着色器补充-1-HLSL与GLSL基础.md)：阶段、输入/输出语义与语言对照。
2. [补充 2：坐标空间与矩阵](图形着色器补充-2-坐标空间与矩阵.md)：空间变换、数学约定与 shader 使用；R.13 当前相机约定以 [D3D12 新版主线](../d3d12/README.md) 为准。
3. [补充 3：缓冲与资源绑定](图形着色器补充-3-缓冲与资源绑定.md)：结构化数据、资源视图与绑定关系。
4. [补充 4：插值与粒子边缘](图形着色器补充-4-插值与粒子边缘.md)：插值后的像素输入与粒子覆盖。
5. [补充 5：真实 3D 粒子 Billboard](图形着色器补充-5-真实3D粒子Billboard.md)：把面向相机的粒子与三维场景结合。

后续读法线、材质与路径追踪时继续参考这些概念，但应区分光栅插值、DXR 重心重建和 CUDA 计算各自的数据来源与执行过程。
