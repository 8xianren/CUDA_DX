# PT.3–PT.5 补课：从重要性采样到面积光

2026-10-09。学习者指出串联回顾没有讲清重要性采样、PT.4 两种半球采样和 PT.5。补课必须逐步连接：目标积分、实际抽样分布、配套 PDF、最终样本权重；不能只列公式。

## 1. 用可手算的例子理解重要性采样

在 [0,1] 上，g(x) 左半段为 1，右半段为 9。积分为 0.5×1+0.5×9=5。

均匀采样 p=1，单样本 Y=g/p 为 1 或 9，各有 50% 概率；期望 5，方差 16。

改为左半段概率 10%、右半段概率 90%。注意这是区间概率：除以区间宽度 0.5 才得到 PDF，分别为 0.2、1.8。

此时左样本贡献 1/0.2=5，右样本贡献 9/1.8=5。每次均为 5，理论零方差。若改了抽样却不除 PDF，会得到 0.1×1+0.9×9=8.2。

抽样实现可用一个 U~Uniform(0,1)：U<0.1 时 x=0.5 U/0.1，否则 x=0.5+0.5(U-0.1)/0.9。输出 x 的分布已改变，输入随机数均匀不代表输出也均匀。

实际渲染难以预知完整被积函数，因此重要性采样通常只匹配已知部分；不良分布也可能增加方差。无偏性来自正确的权重与覆盖条件，低方差来自分布匹配程度。

## 2. PT.4 两种方法都在半球采样

采样域都是命中点法线 N 上方的单位方向。均匀指相同立体角区域具有相同概率，不指 θ 均匀，也不指俯视圆盘上的密度均匀。

设 z=cosθ，dω=|dz|dφ。均匀半球总立体角 2π，所以 pω=1/(2π)。取 z=U1、φ=2πU2，再构造 (sqrt(1-z²)cosφ,sqrt(1-z²)sinφ,z)。

Lambert 的目标被积函数 g(ω)=Li(ω)(ρ/π)cosθ。材质常数已知，余弦也已知，因此选择 pω=cosθ/π 来匹配这一部分。

对 φ 积分得到 z 的边际密度 pz=2z，CDF Fz=z²。逆变换 z=sqrt(U1)；φ 仍均匀。pz=2z 是相对 dz 的密度，pω=z/π 是相对 dω 的密度，不能互换。

法线附近半角 α 的圆锥：均匀采样概率 1-cosα，余弦采样概率 sin²α。α=60° 时为 50% 和 75%；α=30° 时为约 13.40% 和 25%。

单位正交 TBN 将局部方向旋转到世界空间，保持立体角大小，因此保持方向 PDF。两种方法不改变材质，改变的是计算预算分配。

## 3. 权重为什么变简单

Y=Li fr cosθ/pω；Lambert fr=ρ/π。

均匀：Y=2ρLi cosθ。余弦：Y=ρLi。抵消的是同一次采样对应的函数和密度；余弦仍体现在频率上，不可再乘一次。

ρ=0.7、Li=1、cosθ=0.2：均匀样本 Y=0.28，余弦样本 Y=0.7；cosθ=0.9：均匀 Y=1.26，余弦 Y=0.7。单样本是积分估计，可能大于最终结果，并不代表材质增能。

小发光圆锥例：sin²α=0.01，圆锥内 Li=10、外部 Li=0，ρ=0.7。余弦采样命中概率 1%，命中贡献 7，否则 0，期望 0.07。零样本与少量大样本依然造成噪声，因为该采样器没有匹配 Li。

## 4. PT.5：显式抽灯上位置

NEE 在着色点显式连接光源，估计直接照明。灯外方向对此直接照明项为零，因此可以把采样集中到灯；这并不意味着间接照明也为零。

先在面积上写物理积分，避免先背 PDF 转换：

Lo_direct=∫A Le(y→x) fr(x,wi,wo) cosS V(x,y) (cosL/r²) dA。

cosS 来自接收面；cosL/r² 把灯面面积换成着色点看来覆盖的立体角。沿真空射线 Li=Le，并不需要给 Le 额外乘一次衰减。

矩形中心 c，单位正交边轴 u/v，半边长 hu/hv：A=4hu hv；均匀样本 y=c+(2U1-1)hu u+(2U2-1)hv v；pA=1/A。

使用面积 PDF 的样本：Y=Le fr cosS cosL V/(r² pA)。

若换用方向 PDF，由 pA dA=pω dω 得 pω=pA r²/cosL；于是同一样本 Y=Le fr cosS V/pω。两种表达不可混用。

## 6. 可见性、失败路径和权重

对每个抽到的样本，若发光面背向、接收面背向、或被挡住，本次贡献为零。平均时分母仍是总抽样次数，不能只除以未遮挡数量，也不能未经 PDF 调整就不断重抽直到可见。

阴影查询只覆盖着色点到目标灯点之间；命中任意不透明阻挡即可终止。原点偏移后需要以新起点计算射线方向和距离，剔除光源端点；固定 epsilon 仅适用于约定尺度。当前 demo 用原距离近似新距离，不是生产稳健实现。

soft shadow 是不同灯点具有不同可见性后的积分结果，不是将硬阴影模糊。一般也不等于“可见面积百分比 × 无遮挡照明”，因为不同灯点有不同几何权重。

## 7. 函数契约与范围

`pt4_lambert_sampling.cu:52` 的 `sample_local(Strategy,double,double)` 输入两项均匀数，按策略返回局部方向与对应方向 PDF；`:63` 的 `contribution(Frame,Vec3,double,double,double,double*)` 接收世界方向、方向 PDF、ρ、Li，写出样本贡献，返回 false 表示输入或结果无效。输出标量和 RNG 都由调用者持有，CPU 同步调用，没有设备资源所有权交接。

`pt5_direct_lighting.cu:59` 的 `sample_rect(const RectLight&,Vec3,Vec3,Rng*)` 读取灯与着色点/法线，修改调用者 RNG 状态，按值返回 q、wi、距离、两余弦及两种 PDF。单位轴、正面积、有效法线、着色点与灯不重合是前提；代码没有完整验证这些退化输入。

`:85` 的 `nee_area(const RectLight&,Vec3,Vec3,double,Rng*,const Sphere*)` 返回一次面积样本贡献；blocker 为 nullptr 表示没有遮挡球，当前可见性只测试这一颗球。真实渲染器须对整个场景查询遮挡。

多个光源若随机选一盏，还需包含选灯概率 qj：总采样密度为 qj×条件 PDF。若每盏灯分别估计并相加，则不采用同样的随机选灯补偿。PT.6 再处理 BSDF 与灯采样重叠区域的 MIS，不能把两个完整直接照明估计直接相加。

点光用 I 表示辐射强度，E=I cosS V/r²，Lambert Lo=(ρ/π)E；没有普通面积 PDF，也没有 cosL。固定 Le 改变灯面积会改变总功率，不等于固定功率实验。
