# PT.4 Lambert BRDF 与余弦加权半球采样

## 目标与边界

把 PT.1 的渲染方程、PT.2 的世界空间命中法线、PT.3 的 `f/p` 连接起来：在局部半球生成完整方向、转换到世界空间，再按相同测度的 PDF 算一枪出射辐亮度。本节是 CPU 参考积分实验，用 nvcc 编译，但没有 GPU kernel、光线求交、阴影与多次反弹；直接光照/可见性去 PT.5，MIS 去 PT.6。

程序：`learning/sandbox/path_tracing/pt04-lambert/pt4_lambert_sampling.cu`；命令：从 `learning/sandbox/` 执行 `./build.ps1 path_tracing\pt04-lambert\pt4_lambert_sampling.cu`。随机引擎沿用 PCG32；K 次 run 的 seed 固定以便复现；所有统计数字只是本机这个测试 workload。

## 1. 三种空间和一个测度

- 局部切线空间（shading frame）：法线为 `+Z`，`ω_l=(x,y,z)`，`z=cosθ≥0`。
- 世界空间：交点的单位法线 `N` 一般不与 `+Z` 重合；`T,B,N` 构成正交基，`ω_w=xT+yB+zN`。
- 图像/相机空间：PT.2 相机射线从像素而来，命中后本节反弹方向的采样是围绕世界空间表面法线；不是在 NDC 采样。
- 方向积分测度是立体角 `dω = sinθ dθ dφ = |dz|dφ`，其中 `z=cosθ`。正交基变换保长度、夹角及立体角，故局部的 `p_ω` 数值可用于世界方向。非均匀缩放不是正交基，不能直接沿用 PDF。

`Frame make_frame` 先归一化非零法线，选一个不平行的参考轴 `ref`，计算 `T=normalize(ref×N)`、`B=N×T`。接近 `+Z/-Z` 时切换到 Y 参考轴，避免 `ref×N≈0`。输入零法线或 NaN 不符合函数前提：在真实渲染器应在上游验证/回退。本测试分别验证斜法线和两极点的基。

## 2. Lambert 为什么是 rho/pi

在表面局部，每个入射方向都按同一 BRDF 反射：`f_r(ω_i,ω_o)=ρ/π`，`ρ∈[0,1]` 是线性空间反照率（RGB 时按通道处理）。BRDF 单位 `sr^-1`，辐亮度 `Li` 单位 `W·m^-2·sr^-1`，余弦无量纲，PDF 相对立体角时也为 `sr^-1`；`Li*f_r*cos/p_ω` 恢复辐亮度单位。

为何 `1/π`？白炉输入 `Li=L` 均匀、无遮挡：

```
Lo = ∫H Li * (ρ/π) * cosθ dω
   = L * (ρ/π) * π = ρL
```

因为 `∫H cosθ dω=π`，这是 PT.1 的投影立体角；错写 `f_r=ρ` 会反射 `πρL`，可能凭空增能。`ρ=1` 的理想白漫反射在白炉返回 L，`ρ<1` 返回较低值。此白炉只检查一次反射；不代表处理多次反弹、发光、能量传输或光源可见性。

## 3. 两套生成方向的规则：采样必须配 PDF

取 PCG32 的两个 `(0,1)` 均匀数 `u1,u2`，方位角 `φ=2πu2`，水平方向半径 `r=sqrt(1-z²)`，局部方向 `(r cosφ,r sinφ,z)`。

| 策略 | z | 方向 PDF（相对 dω） | z 的边际 PDF（相对 dz） |
|---|---|---|---|
| 均匀立体角半球 | `u1` | `1/(2π)` | `1` |
| 余弦加权半球 | `sqrt(u1)` | `z/π` | `2z` |

余弦密度的推导：`p_ω=z/π` 对 φ 积分，`p_z(z)=∫_0^{2π}(z/π)dφ=2z`，其 CDF 为 `C_z(z)=z²`，逆变换 `z=sqrt(u1)`。千万不要把 `2z` 塞给相对 `dω` 的渲染方程。`∫_H p_ω dω=1`：均匀为 `2π/(2π)`；余弦为 `(1/π)∫cosθ dω=1`。直接令 θ 均匀不会得到立体角均匀。

`Sample {Vec3 wi; double pdf_omega;}` 明确保存局部方向和对应的立体角 PDF；`to_world` 后检查 `dot(N,wi_world)` 是否与局部 z 一致。PCG 的 `(u32+0.5)/2^32` 排除零端点，测试仍单独拒绝 `pdf<=0`；若应用反弹追踪，还需对法线背面、非有限值作容错。代码中 `Rng {uint64_t state,inc}` 为调用者持有，种子/stream/调用顺序决定重播；这里未建立跨分支 `(pixel,sample,dimension)` 的生产契约。

## 4. 每枪权重的四项及偏差

对给定世界方向 `wi`，测试函数 `contribution` 计算：

```
cosθ = dot(N,wi)
fr   = rho / pi
Y    = Li(wi) * fr * cosθ / p_ω(wi)
```

`Li` 是沿该方向返回的**入射辐亮度**，本节直接给定解析函数；不是随机 PDF，也不是本节自己求交得到的亮度。`fr` 衡量材料如何反射，`cosθ` 是投影几何，`p_ω` 是实际抽该方向的密度；`1/N ΣY` 估计 `Lo`，不是将单枪当真值。

均匀采样：`Y=2ρ Li z`；余弦加权：`Y=ρ Li`。若 `Li=L` 常数，余弦采样每枪恰好 `ρL`，方差零；一般 `Li(wi)` 会变化，余弦采样**不保证**总低方差。小光源和可见性变化使简单 BSDF 采样仍噪，PT.5–PT.6 处理。

三种错误的白炉极限（`L=1`，`ρ=0.7`）：

- 余弦采样却按均匀 PDF 除：`Y=2ρz`，`E_cos[z]=∫_0^1 z(2z)dz=2/3`，于是 `E[Y]=4ρ/3=0.93333` 而非 `0.7`；这是偏差，不是方差。
- 正确 PDF，但漏乘 `cosθ`：`E[Y]=∫(ρ/π)dω=2ρ=1.4`；会增能。
- 正确 PDF，却在原式上重复乘一次 `cosθ`：`E[Y]=∫(ρ/π)z²dω = (ρ/π)*(2π/3)=2ρ/3≈0.46667`；会偏暗。

这里“重复乘”指在已有 `fr*Li*cos/pdf` 之外又乘一次；如果你用已经化简好的 `ρLi` 再乘 z，也得到 `2ρ/3`。不要同时先化简、后又调用一次含余弦的权重函数。

## 5. 白炉和非均匀照明：不能把方差与单次误差混淆

测试在斜世界法线 `N=normalize(0.31,-0.70,0.64)` 下，64 次独立 run，每次 256 SPP。`var_runs` 是 **64 个完整积分估计值之间的样本方差**；不是单枪 `Var(Y)`，也不是单次绝对误差；由于使用固定 PCG 流只代表这套测试。

白炉 `Li=1`、`ρ=0.7`，精确 `Lo=0.7`：均匀均值 0.696709505、run 方差 0.000784669867；余弦均值 0.700000000、run 方差约 `3.9e-34`（浮点舍入）。均匀 run 均值低于解析值不是“偏差”，只是这 64 次固定种子的抽样误差。

非恒定照明 `Li(wi)=1+0.5 z`：

```
Lo = (ρ/π) ∫(1+0.5z)z dω
   = ρ [1+0.5*(2/3)] = 4ρ/3 = 0.933333333...
```

均匀均值 0.928573299、run 方差 `0.00181826825`；余弦均值 0.932722292、run 方差 `2.37089077e-05`。方差在这个解析光场、固定 SPP 下更低；不是“余弦对所有场景最优”的证明。

另一项独立验收在 `(z,φ)` 网格上用中点积分验证两种 PDF 质量都是 1，并对每套采样器的 65536 个完整世界方向检查半球、单位长度、点积与 PDF；这不是 CUDA GPU 实测。

## 6. 教学与引擎对照 / 下一步

UE 等生产路径追踪会处理多种 BSDF、光源采样、可见性、纹理、法线贴图、混合 PDF、多次反弹和随机化 Sobol 等；本节仅把单次 Lambert 权重做成解析可验的 CPU 参考。相同底层积分规则仍是 `Li * fr * |N·wi| / p_ω`，两边都必须保持采样与 PDF/测度配套。着色法线与几何法线差异可能导致能量与漏光问题，本节使用同一法线并暂缓到多 BSDF/路径阶段讨论；本节未把近似方案称为引擎实现。

练习：令 `ρ=0.4`、`Li=2`，求白炉输出；若采样方向局部 `z=0.25`，两种采样的单枪权重各是多少？再解释为什么均匀采样的这一枪不等于白炉真值。下一节 PT.5 将让 `Li` 不再是给定解析函数，而是加入光源、距离、遮挡、面积域与立体角域 PDF 转换。
