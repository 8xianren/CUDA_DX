# PT.11 静态时空复用与独立统计

2026-10-21。[代码入口](../../sandbox/path_tracing/restir-di/README.md)，前接[Reservoir合并与相关性](PT.11-Reservoir合并与相关性.md)。本节完成固定场景与固定网格的实际时间/空间复用缓冲、四开关对照及独立重复实验。运动、重投影、法线/深度拒绝和动态可见性仍待下一节，PT.11整章未完成。

## 上节自测答案

1. 源M=4和12不能直接都改成1后继续沿用原权重公式，否则改变了每组在最终估计中的系数。当前推导使用t_dst*W_src*M_src和总M，两处必须一致。另行设计等组权的无偏混合可能成立，但需重新定义权重，不能只改一个字段。
2. 重复同一来源不创造新随机信息。按上节固定系数合并，输出可与使用一次完全相同；不能根据翻倍M就套独立样本方差下降公式。
3. 源评分为零而目标贡献非零，意味着支持域缺失。不能靠合并公式恢复从未被保留的贡献，需改提议/评分支持、拒绝或采用有明确条件的校正。

## 从数据依赖设计四个阶段

每像素每帧生成8个新候选，得到fresh。时间复用将fresh与上一帧同一表面位置的history合并，得到temporal。空间复用读取已经完整生成的temporal邻域，写spatial。最后在当前表面点重评估选中样本贡献与可见性。

本节表面和网格固定，因此上一帧同一pixel恰好对应同一世界点，是恒等历史映射；这个事实来自当前几何假设，不是运动场景的普遍规则。

```text
本帧新候选 → fresh ──┐
上一帧history ───────┴→ temporal → 读取中心/上下左右 → spatial → 当前可见性 → RGB
                           └────→ 保存为下一帧history
```

空间阶段不能边读边覆盖temporal。假如先更新左像素，右像素读到的可能是“已经混入邻居”的新结果；反向遍历又会读到另一组历史，形成顺序依赖。当前实现三个完整循环分开执行，源缓冲只读，每个目标写独立输出。

为控制本节相关性，历史保存空间复用前的temporal，不把spatial再反馈为下一帧history。生产实现可以选择其他调度，但必须分析重复传播、计数与相关性；不能把本课选择说成所有ReSTIR实现的唯一方式。

## 时间复用的计数与空间邻域

第k帧（从1开始）如果开启时间复用，每像素temporal的M=8k；关闭则M=8。本节最多16帧，因此history最大M=128。

空间复用读取中心和上下左右四邻居，每项根据目标位置重算t，再调用Merge。边缘越界项跳过，不复制边界像素凑满5项。每像素可用邻居数为3、4或5，spatial.M为邻居源M之和；第16帧内部像素最大M=5*128=640。

这个M是代表的候选计数，不自动等于像素间或帧间的独立样本数量。邻近输出共享temporal源，因此输出之间存在空间相关性。当前同一像素的历史跨帧也重复使用，不能把连续16帧当作16次独立试验。

## 接口、布局、所有权与失败路径

`reuse_pipeline.h`中的StaticReuse拥有4个vector<LightReservoir>：fresh、temporal、spatial、history；另有vector<V3>输出。Reservoir为56B，RGB double向量24B，本节96像素的上述逻辑数据总计96*(4*56+24)=23808B，不含vector对象、场景、统计数组或分配器开销，不能称为整个进程内存峰值。

```cpp
explicit StaticReuse(Grid g);
void Step(const Scene& scene, uint64_t seed,
          bool useTemporal, bool useSpatial, bool reverse=false);
```

g确定12×8网格与接收面坐标；构造检查非零尺寸和容量上限，预分配各缓冲。scene只读借用，seed区分独立运行，两个bool控制复用，reverse只改变像素遍历顺序。对象内部frame每次Step加1，随机流由seed/frame/pixel/stage决定，遍历先后不会改变某像素使用的随机数。

每阶段CPU循环完成后才进入下一阶段，所以无需额外GPU同步API；这不是已经实现的GPU dispatch图。history=temporal是深拷贝数值，不让两个vector别名指向同一可变数组。所有reservoir按值拥有样本身份，不拥有灯/场景资源。

本接口前置为固定Scene、固定网格；改变相机、几何或尺寸必须重新构造对象，本节尚不支持保留动态历史。主测试检查有限非负输出、计数、RGB统计、文件写入，失败抛异常并返回1。无限期历史增长、M上限策略与动态拒绝在后续单独处理，不能把16帧教学测试当作长期生产方案。

## 为什么使用256次独立运行

每次运行都重新构造4套空历史，使用不同种子，推进16帧。对某个固定像素、固定帧，收集256个独立运行的结果计算均值和方差。

这样第16帧的256个结果来自256段独立历史，而不是从同一段历史抽取256帧。估计标准误差采用各像素跨run的样本方差；没有把相邻像素视为独立样本来缩小误差条。

参考值是同一解析场景的分区面积求积，每点128与64对照。每方法/帧/像素逐RGB检查容差6SE+4倍参考差+1e-8，全部通过。记录的mean_error_squared仍是有限样本均值误差，包含随机误差，不是已知纯偏差。经验MSE按s²*(R-1)/R+(mean-reference)²计算。

本节网格12×8，不同于上节24×16；空间采样位置不同，不能把两个网格的全图平均亮度直接当成同一个参考数。

|模式|时间复用|空间复用|
|---|---|---|
|fresh|关闭|关闭|
|temporal|开启|关闭|
|spatial|关闭|开启|

两场景、4模式、16帧、96像素共12288个方法/帧/像素记录，逐RGB统计无超限。正序/反序遍历4帧逐RGB完全相同；history/spatial的M逐帧逐像素核对通过。

## 为什么遮挡噪声会趋缓

设某像素未遮挡亮度积分为Z，含遮挡真实积分为I。考虑理想模型：样本恰按p(y)=t(y)/Z分布、Z已知，t为未遮挡亮度。最终一次估计是Z*V，其中V是0/1可见性。

此时P(V=1)=I/Z，所以均值为I，方差为：

\[
\operatorname{Var}(ZV)=Z^2\frac IZ\left(1-\frac IZ\right)=I(Z-I).
\]

用本节参考图计算该模型的平均方差为.04697835，与有板复用后的约.047量级接近。这说明即便候选选择已很好，最终只查询一个样本的遮挡仍留下随机性。它是特定目标分布/单样本模型的残余方差，不是所有估计器的普适下界，也不是对有限候选和复用相关性的完整预测。

增加最终独立可见性样本、设计含可见性的有效采样，或另做正确的颜色积累，都属于不同改进。不能直接删除遮挡让图平滑，上一节已经验证那会漏光。本节也没有把reservoir历史混同为颜色历史。
