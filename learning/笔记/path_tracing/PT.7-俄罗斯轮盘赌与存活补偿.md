# PT.7：俄罗斯轮盘赌与存活补偿

2026-10-21。[前课：DXR多反弹与MIS](PT.7-DXR多反弹与MIS状态.md)。[代码与命令](../../sandbox/path_tracing/pt07-throughput/README.md)。本课在原shader上增加随机终止，完成PT.7的限定盒腔验收；下一课PT.8。一般材质、介质折射、通用网格数值偏移及交互性能仍不属于当前实现。

## 上节答案

到达下一发光体时，MIS使用上一顶点生成当前射线的BSDF PDF，以及从上一顶点评估的光源PDF。当前发光权重不能写入未来beta。深度K仍可收取经过K次散射到达的发光，但在该顶点做NEE会再发生一次散射，越过此处的深度约定。

## 从随机终止的目标推导补偿

当前已累计L，后续尚未计算的贡献为随机变量X。想以存活概率s继续，以1-s终止，从而省去一部分未来求交。若只终止而不补偿，后续贡献变为BX，其中B∈{0,1}且P(B=1)=s，期望为s E[X]，系统性变暗。

令存活时乘系数a，则E[BaX]=saE[X]。要求原期望不变，解得a=1/s。所以后续估计是Y=BX/s，死亡时0，存活时X/s。实际不预先计算X，而把承担未来贡献的beta除以s。

更严格地，给定当前已知历史H（包括已经采样的BSDF方向和更新后的beta），选择s(H)，再使用独立的轮盘赌随机数。条件期望E[BX/s|H]=E[X|H]，随后对H求期望，仍保持目标。s可以随路径状态改变，不要求每次相同，但潜在非零后续贡献不能被赋予s=0。

例：100条路径的未来贡献各为.02，以s=.25抽样，平均25条存活，每条携带.08；期望总量仍2。实际存活数随机，单次实验不要求恰好25条。若漏补偿，期望只剩.5。

不要把存活概率s和终止概率q=1-s混淆：代码是beta/=s，若变量命名为q则应除1-q。已有L不能整体除s，当前已经算完的发光/NEE也不被删除。

## 方差与计算量的交换

固定X=x时，E[Y²]=x²/s，Var(Y)=x²(1/s-1)。所以轮盘赌本身增加随机波动，并非降噪器。减少无效长路径计算有机会提升固定时间下的效率，但需要把方差、平均工作量、SIMT分歧和实际GPU计时一起衡量。

本实验只验证实际TraceRay次数和追踪深度下降，未测GPU时间；大量逐顶点诊断写回和逐次Fence也不代表生产渲染器的性能。

## 本课的存活概率与放置位置

每个当前顶点先：收发光→做NEE→采样BSDF→更新beta。然后在即将尝试到达depth+1时做RR，成功后再追踪下一条射线。rrStart=3表示depth0/1/2必定访问，第一次在depth2末尾决定是否到达depth3。

本反射RGB测试使用s=clamp(max(betaR,betaG,betaB),.05,.95)，beta为刚乘完f*cos/pdf的值。如果三个通道全零，s=0可安全停止；已有自发光仍保留。

使用最大通道是保留强颜色通道的一种启发式，不是无偏性所要求的唯一选择，也不等于真实未来贡献。三个RGB通道共用同一个生死结果，存活后三个通道都除同一个s。

下限.05限制单次补偿倍率不超过20，减少过于罕见而权重很大的样本；会多保留一些弱路径。上限.95让较强路径也有终止机会，同时可能引入不必要方差；不是所有渲染器都采用此上限。s=1合法，退化为不终止且不放大。推迟RR可以保留短路径贡献，但增加基础工作量。折射下的eta尺度不在本课公式内，PT.8再讲，不能把这套反射测试当作完整介质策略。

## 与MIS的关系

当前NEE和发光已经写入L，RR只选择尚未计算的未来项。存活后beta除s，previousPdf仍保存上一跳的条件方向PDF，不在本实现里再乘s；随机终止概率已通过beta补偿。

这与上一课“不能把局部MIS权重乘入beta”并不矛盾：MIS权重只分配某项直接光连接，RR补偿的是所有被一起随机保留的后续贡献。具体放置必须和估计器推导一致，不能把两者都简单视作随意缩放beta。

## 代码、布局、资源与失败路径

`gpu_path.hlsl`沿用同一RayGen/ClosestHit/NEE实现，新增rrRng独立状态，不移动原灯/BSDF采样序列；相同seed的幸存路径可与关闭RR模式配对。该整数流是教学确定性伪随机序列，不宣称严格数学独立或采样质量最优。

核心代码在BSDF beta更新之后：

```hlsl
float peak = max(beta.x, max(beta.y, beta.z));
float survival = peak > 0 ? clamp(peak, c.rrMin, c.rrMax) : 0;
float u = Uniform(rrRng);
bool keep = u < survival;
if (keep && c.rrMode == 1) beta /= survival;
// keep=false保留已有L，填好尾槽后退出；不再发射后续射线。
```

rrMode0关闭，1正确补偿，2故意漏补偿。rrStart定义首次尝试到达的深度，rrMin/rrMax定义合法范围(0<min≤max≤1)。配置仍64B，偏移48的原保留区改为uint rrMode/rrStart、float rrMin/rrMax；C++/HLSL字段和static_assert同步。

PathRecord由112B扩展为128B，新增偏移112的float4 roulette，依次为s/u/是否决策/是否继续。已有材质+1字段作为到达标记，0表示未访问槽；真正封闭盒miss仍是错误并带错误位，不能和正常RR终止混淆。

每条初始路径保留K+1槽。终止后的槽明确写零beta、零射线计数、正确depth和最终L；最终每条初始路径的L都参与平均，不能只对幸存路径求平均。128B×17×4096=8912896B输出。每个RayGen独占自己的槽，没有原子操作或新增同步API。

`gpu_path_dispatch.cpp`抽出上课Run函数供两个测试共用。Run(context,frame,cfg,shader)检查路径数、深度、材质、RR范围，调用已有DispatchRayBuffer并复制成PathRecord数组；旧gpu_path_test默认rrMode0。资源继续沿用t0 TLAS/t1对象/t2配置/u0结果，UAV→COPY_SOURCE→READBACK→Fence等待→Map；所有局部GPU资源保持到Fence完成，CPU持有返回vector。无设备恢复、异步帧复用或性能优化。

`gpu_path_reference.h`逐bit重放RR整数流，检查s、u、生死决定、存活补偿和死亡尾槽；以double累积实际存活历史下的beta，继续核对几何、PDF、MIS与辐亮度。几何与轮盘赌状态错误、非有限值、非法参数、GPU异常或统计回归失败都令进程非零退出。

## 验收设计

固定共同K=16，同一个glTF盒腔、Power MIS、16seed×4096初始路径；分别关闭RR、正确RR、漏补偿RR。独立有限解析参考由导入后的float rho/Le计算。对相同seed的开关均值作配对差，并从16个差值计算SE；这样不错误假定两组样本独立。SE是seed均值的标准误，不是单条路径方差。

均值对参考用6SE+2e-6回归阈值，配对差用4SE+2e-6；这些是宽松回归标准，不是测试证明无偏，也不是严格置信区间。数学保证来自条件期望推导；本实现另有上一课盒棱边2e-6几何近似，仍需明确保留。

边界：s=1的辐亮度/beta与关闭模式逐值相同；弱反射率触发下限、强反射率触发上限；beta全零给s=0并保留已有发光。默认关闭RR的上一课全部模式、K0/K1/rho0/Le0回归通过。

## 固定深度仍有偏

RR正确补偿保持的是共同截断目标L16的期望，不能自动补回16次散射之后的贡献。本例红通道无限参考约.2500000186，有限目标约.2499577019，尾项约4.23e-5。RR的随机误差可以使某次均值高于无限参考；这不是负截断偏差或凭空增能，而是采样波动。

若去掉确定性截断，在适当可积性及终止条件下，RR能对无限路径展开保持无偏；本GPU诊断使用有限槽和共同K，不声称已做无限路径实验。生产系统常有最大深度或其他限制，必须区分这些限制与RR各自影响。
