## PT.1：物理量与积分测度

- 通量 Φ：W；辐射强度 I：W/sr；辐照度 E：W/m²；辐亮度 L：W/(m²·sr)。
- `dω=sinθ dθ dφ`，半球 `∫dω=2π`；投影余弦给出 `∫cosθ dω=π`。
- Lambert `fr=ρ/π`，ρ 是无量纲反射率。因为 `∫fr cosθ dω=ρ`，分母是 π。
- 均匀入射 L0 下 `Lo=ρL0`；省略余弦会得到两倍结果。
- 辐亮度沿无遮挡、无吸收散射的真空射线保持不变；接收照度仍可随光源距离改变，因为其覆盖的立体角改变。

代码：`learning/sandbox/path_tracing/pt01-radiometry/pt1_radiometry.cu:53`。
重跑：半球积分 6.283185461217，投影积分 3.141592961600；ρ=0.6、Li=2.5 得 1.500000147064。

## PT.2：空间射线与可见性

射线 `P(t)=O+tD`；本课 D 归一化，因此 t 是世界空间距离。像素中心映射到世界成像平面，再从针孔朝该点发射射线。求交在世界空间，像素/NDC 只参与生成方向。

- 球：代入球面方程，解二次方程，选择有效区间内最近根。
- 三角形：解 `O+tD=v0+u(v1-v0)+v(v2-v0)`；要求 `u≥0,v≥0,u+v≤1`，重心权重是 `(1-u-v,u,v)`。
- AABB：分别求三轴 slab 的参数区间，再取交集。作为 BVH 包围体时，命中盒子只意味着需继续检查内部几何。
- 最近命中：保存最小合法 t；本课通过不断缩短 tmax 实现。
- 自相交：浮点误差可能使新射线再次命中出发面；固定 epsilon 是教学简化，过大也会漏光。

代码：`pt2_ray_geometry.cu:207` 相机射线，`:224` 球，`:261` 三角形，`:297` AABB，`:365` 最近命中。

## PT.3：蒙特卡洛和 PDF

`J=∫g(x)dx`，采样 `X~p`，单样本 `Y=g(X)/p(X)`，估计 `Jhat=(ΣY)/N`。
因为 `E[Y]=∫(g/p)p dx=J`，正确配套的 PDF 消除了非均匀抽样的频率差异。
PDF 是密度，区域概率是其积分；值可超过 1。p 必须归一化并覆盖被积函数的非零贡献区域（允许零测集例外）。

无偏指重复实验的期望正确；单次误差不为零并不证明有偏。独立同分布、有限方差下，平均值方差为 Var(Y)/N，标准误差按 1/√N 下降；单次实际误差不保证逐步下降。

均匀采样保持常密度；随机分层使样本分散覆盖各区间；重要性采样使分布更贴近被积函数。PCG32 的种子、流和调用顺序共同决定可复现序列。

代码：`pt3_monte_carlo.cu:90` 一维函数/PDF，`:125` 半球采样，`:267` 故意漏除 PDF。
重跑：`p=3x²` 估计 `∫x²dx` 为 0.3333333333；均匀半球漏除 PDF 得 0.5018233585，目标原为 π，错误极限是 0.5。

## PT.4：Lambert 与余弦采样

通用方向样本贡献：`Y=Li*(ρ/π)*max(0,N·wi)/pω`。

- 均匀半球：`pω=1/(2π)`，贡献 `2ρLi cosθ`。
- 余弦半球：`pω=cosθ/π`，贡献简化为 `ρLi`；余弦效应已进入抽样频率，不能额外再乘一次。

本课采样 `z=√u1, φ=2πu2`，局部方向 `(√(1-z²)cosφ, √(1-z²)sinφ,z)`，通过正交基变换 `wi=xT+yB+zN`。纯正交变换保持立体角，PDF 不需额外缩放。

白炉测试让所有入射方向 Li=1；ρ=0.7 时应输出 0.7。恒定 Li 下余弦采样每个样本相同，理想方差为零；真实照明和遮挡会让 Li 随方向改变，方差重新出现。

代码：`pt4_lambert_sampling.cu:38` 正交基，`:52` 采样，`:63` 权重。
重跑：白炉余弦均值 0.700000000；Li=1+0.5cosθ 时，均匀/余弦完整 run 方差分别 0.00181826825 / 0.0000237089077（64 runs，每 run 256 样本）。

## PT.5：光源采样与 NEE

NEE 显式连接当前着色点 x 与光源样本 y，估计直接光照，避免只靠随机反弹偶然命中小灯。

单面矩形面积 A，均匀面积抽样 `pA=1/A`。设 `wi=(y-x)/r`：

`cosS=max(0,N·wi)`，`cosL=max(0,NL·(-wi))`。

从着色点看光源面片，`dω=cosL/r² dA`；概率质量守恒 `pA dA=pω dω`，因此 `pω=pA*r²/cosL`。

同一估计量的两种写法：

`Y=Le*fr*cosS*V/pω`

`Y=Le*fr*cosS*cosL*V/(r²*pA)`。

V 是可见性：无遮挡为 1，有遮挡为 0。两种写法不能混搭；用了方向 PDF 后再乘 cosL 或除 r² 会重复计算几何项。

阴影射线仅测试着色点到光源之间的有限段；光源后的物体不应遮挡。偏移起点后，稳健实现应以新起点重算到目标的距离/端点界限；当前 demo 仍使用原始距离近似，不是通用稳健性证明。

点光源用辐射强度 I 表示：`E=I*cosS/r²*V`，Lambert `Lo=(ρ/π)E`。点光无普通有限面积 PDF，也没有表面法线或 cosL。

软阴影来自同一着色点看得到部分发光面积。固定 Le 改面积会改变功率：均匀单面 Lambert 发光面 `Φ=πA Le`；固定功率是另一种实验约定。
