## 前节自测答案

1. 连续帧共享reservoir，不能将它们作为独立观测估计标准误。我们固定某一帧，在256次从空历史启动的独立run之间统计；不同像素也不假设独立。
2. 本课保存temporal作为下一帧history，避免在受控基线中反复反馈空间合并结果。生产算法可以采用其他反馈方案，但须重新处理相关性、权重和计数，不能声称这是唯一正确方式。
3. 目标评分不含可见性时，增加候选并不等于平均多条阴影射线。最终只有选中样本的一次可见性，阴影附近仍可有明显方差。

## 1. 要找的是历史表面，不是相同屏幕下标

相机向右移动时，当前像素i看到的世界点变了。直接取history[i]混淆了屏幕地址与世界表面。重投影是把当前世界点放到上一帧相机下，求它过去的屏幕位置；位置匹配后还必须确认旧像素存的是合适的表面。

本课约定正交相机朝-Z，窗口世界宽E、高H，中心(cx,cy)，图像W×N，列i和行j从0开始，行向世界+Y增加。像素中心射线：

    x = cx + E*((i+.5)/W-.5)
    y = cy + H*((j+.5)/N-.5)

接收面z=h+s*x，代入得到真实交点。平面隐式方程z-h-s*x=0的梯度为(-s,0,1)，归一化得到法线。改变s真的改变了平面，不能只篡改normal标签。

将当前世界点x代入上一帧相机并反解：

    u = (x-cx_prev)/E_prev + .5
    i_cont = W_prev*u - .5
    i_nearest = floor(W_prev*u)

先检查0<=u<1、0<=v<1，再读取floor(v*N_prev)*W_prev+floor(u*W_prev)。这是半开窗口，右/上边界不属于图像。最近像素中心在等距边界采用向较大下标取舍。此处没有透视除法，也不是D3D的上端起点约定。

W=12，E=2.4，像素宽.2。相机中心向右移动.2后，当前i映射到旧i+1，末列越界，因此88个接受、8个越界。程序逐像素验证这个解析对应关系，不能仅凭最终图像看起来正确。

代码：dynamic_surface.h中的MakeSurface和Reproject。

## 2. 深度必须在同一个相机坐标约定下比较

旧深度为d_old=z_camera_old-z_surface_old。把当前点放到旧相机下，预测深度应为d_expected=z_camera_old-z_surface_now，比较abs(d_expected-d_old)。直接拿当前相机深度比较会把相机自身Z移动误认为物体变形。

本课Compatible依次检查：旧表面有效、identity相同、法线点积>=.95、深度差<=阈值。temporal阈值.05世界单位，spatial阈值.15；法线阈值约18.2度。阈值是课程尺度下的工程选择，不是正确性的数学证明，也不能照抄到任意尺度。

相机Z从4到4.3但表面不变时，96像素接受；表面抬高.25时96像素depth拒绝；s从0变为.4时法线点积1/sqrt(1.16)约.9285，因此96像素normal拒绝。法线先检查，尽管该次变化也可改变深度，日志只记录首个拒绝原因。

identity是几何表面身份，不等同于光源ID。右侧面消失时当前无表面，输出黑色并清空历史M；再次出现时旧表面无效，拒绝旧历史。这是显露区域的最小案例，不是完整物体运动向量实现。本课只通过相机映射静态世界点，物体变化采用保守拒绝，没有追踪同一运动物体的旧世界位置。

## 3. 拒绝历史的实际动作

每个有效当前像素先产生8个fresh候选，时间阶段先合并fresh，再决定是否合并历史。拒绝历史时仍有M=8的当前估计，绝不是把像素清成黑色。当前表面本身无效时才是M=0、黑色。

全局重置触发：camera.cut、分辨率变化、lightRevision变化。revision由调用者维护；它不是自动检测场景变化的魔法。光源ID/面积参数化改变必须令旧样本失效或采用严格映射，本课直接重置。测试第9帧修改灯发光并增加revision，证明重置确实绕开旧候选；没有声称“所有发光强度变化都数学上必须重置”。

每个重置帧另建空流水线，在相同seed、frameNumber及空间设置下生成结果。256 runs共55296个像素对照，逐RGB绝对差之和<1e-12，temporal.M=8。比较对象仍启用当前空间合并；fresh-only指不使用时间历史，不是关闭所有复用。

## 4. 当前积分、评分支持域与可见性

灯面固定z=2且朝下，表面点x、法线n，灯样本y，d=y-x，r²=d·d，h=2-x.z。面积积分几何因子由两个余弦和距离平方得到：

    cos_receiver=max(0,n·d)/r
    cos_light=h/r
    G=cos_receiver*cos_light/r²=max(0,n·d)*h/r⁴
    F0=Le*(rho/pi)*G
    F=F0*V_current

先均匀选3个灯，再在选中灯上均匀选面积点，qA=1/(3*A_light)。动态目标t=max(1e-8,luminance(F0))。这个正下限只改变选择评分，最终F不加下限，背面贡献仍可以为0。用途是固定灯域上维持支持：源表面的零贡献方向，换了接收表面后可能非零。若源评分直接为0，该历史源不能单独代表新目标的这部分积分；光有几何阈值无法修复这一点。

在固定灯面积域上复用同一个灯点，没有重新参数化，Jacobian=1；合并权重仍为t_current(y)*W_source*M_source。接受/拒绝在本实验中只依赖固定几何而不依赖随机选中灯样本，候选数量也由几何和帧数确定。正评分、统一测度、正确源权重共同支持上一节的期望推导；随意添加依赖样本的拒绝规则不能自动沿用该证明。

遮挡板位于z=1，射线线段x+a*(y-x)与板相交需满足：x.z+a*(2-x.z)=1，故a=(1-x.z)/(2-x.z)。交点XY落在板范围且0<a<1，才被挡住。板移动不改变灯候选身份，也不改变不含V的目标；可以保留历史，但输出必须用当前板位置查询V。

错误负对照保留当前选中灯、当前F0和W，仅将可见性改为上一帧遮挡几何的查询结果。它隔离的是旧遮挡关系错误，并没有实现“缓存上一帧选中样本的一位V”。两者不要混称。

## 5. 接口、所有权、阶段顺序和失败路径

```cpp
void DynamicReuse::Step(
    const Scene& scene, const CameraGrid& camera,
    const SurfaceConfig& geometry,
    uint64_t seed, uint64_t frameNumber,
    bool useTemporal=true, bool useSpatial=true);
```

scene只读借用当前灯与遮挡板；camera提供图像尺寸、世界窗口、相机Z、cut与lightRevision；geometry提供平面高度/斜率/身份/右侧是否存在；seed和frameNumber确定随机身份；两个开关控制时间/空间合并。返回void，结果存在对象拥有的output，索引为row*width+column。

Surface按值存position、normal、depth、identity、valid。LightSample仍是light/u/v，CPU布局24B；LightReservoir保存样本、累计权重、选中评分、M和有效标志，CPU布局56B。这里没有生产HLSL结构打包约定。

流水线对象拥有fresh/temporal/spatial/history四个vector以及当前/旧Surface、RGB输出、重投影下标、拒绝原因与计数。调用者不接管这些内存。

顺序：完成所有fresh -> temporal读取旧history -> spatial只读完整temporal -> 当前可见性输出 -> history=temporal，oldSurfaces=surfaces，保存相机。保存的是空间前历史。所有阶段为串行CPU循环，顺序自然建立依赖；没有CUDA stream、D3D资源状态或GPU Fence。GPU移植必须另外建立dispatch间读写依赖，不能原地同时读写邻域表。

入口拒绝零尺寸、超过1048576像素、非正窗口范围；课程接收面Z限制为(-2,.9)，保证当前解析几何关系。异常由验证程序捕获，返回非零；脚本检查构建和运行退出码。历史在正常步骤末尾更新，但对象当前工作缓冲可能已被改写，不承诺任意异常下整个对象事务回滚；多次vector赋值遇到内存分配失败也没有强异常保证。此教学接口要求调用者提供有限合法场景数据，不是已覆盖任意NaN/坏灯数据的公共API。

## 6. 实测

12帧固定事件序列，256个独立run。每个frame/pixel的RGB均值对独立分区灯面求积；64/32分辨率差作数值容差估计，阈值6SE+4*差+1e-8，失败像素0。SE来自跨run样本方差，不能通过把相关像素当独立来缩小它。这个有限测试不证明所有场景无偏。

|帧索引|事件|结果|
|---|---|---|
|0|初帧|96无历史|
|1|静止|96接受|
|2|相机右移一像素|88接受、8越界|
|3|板移动、相机Z改变|96接受，输出查询当前V|
|4|表面抬高|96深度拒绝|
|5|平面倾斜|96法线拒绝|

## 7. 边界与下一节

商业实时实现通常需要G-buffer、运动信息、透视相机、对象变形、历史寿命、资源压缩和GPU同步；本课保留可独立求积的平面/矩形场景来隔离概率与历史错误。相同机制是几何对应、源候选再评分、正确归一化与当前可见性；不宣称复现UE算法。

这里只有12帧，无长期M上限/年龄衰减策略，没有对象运动向量，没有颜色历史滤波。对M随意截断可能破坏归一化，不能仅当整数溢出修复。后续先推导间接路径重连接的Jacobian与支持限制，再对照UE的实际ReSTIR Gather源码。
