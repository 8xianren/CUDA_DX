# PT.11 面积灯 RIS 与可见性验收

2026-10-21。[代码入口](../../sandbox/path_tracing/restir-di/README.md)，前接[Reservoir与RIS推导](PT.11-Reservoir与RIS权重推导.md)。本节完成真实平面面积灯/遮挡板几何的CPU直接光对照，仍无时间/空间复用，PT.11整体未完成。PT.9 Compute剩余分析按用户授权跳过，不再作为课程门槛。

## 上节答案

1. 所有评分乘10，w和S都乘10，替换概率w/S不变；最终W=S/(Mt)也不变。这里是同一reservoir中所有候选使用同一个正缩放，不能把不同候选随意乘不同系数。
2. M统计原始抽样次数，零权也是抽到的一种结果。只计非零项会改变分母并产生条件筛选偏差。上节q=(1/2,1/2)、F=t=(0,2)、两候选反例的错误期望为3，正确值为2。
3. 评分可暂不含可见性，但最终真实F必须包含可见性。被遮挡的高分候选最终返回零，不允许把它当作可见，也不能随意丢掉后重抽直到可见而保持旧权重。

## 从真实几何建立积分

接收面位于z=0，法线+Z，Lambert反射率rho=.7。三盏不重叠矩形灯位于z=2，法线-Z；不透明遮挡板位于z=1，x范围[.1,.65]、y范围[-.35,.35]。

|灯|x范围|y范围|面积|线性RGB辐亮度|
|---|---|---|---:|---|
|0|[-1.6,-.8]|[-.4,.4]|.64|(1,.4,.2)|
|1|[-.5,.5]|[-.5,.5]|1|(4,8,2)|
|2|[.8,1.6]|[-.4,.4]|.64|(25,8,4)|

三盏灯不是“数百万光源”性能演示；它们用于验证颜色差异、重要性评分和遮挡纠正。24×16网格直接对应接收面的表面点，不涉及相机射线、间接光、反射贴图或显示窗口。

设表面点x=(x0,y0,0)，灯样本y=(xl,yl,2)，r²=(xl−x0)²+(yl−y0)²+4。因为两法线相向，cosX=cosL=2/r。面积域RGB贡献因此为：

\[
F_A(y)=L_e(y)\frac{\rho}{\pi}V(x,y)\frac{\cos X\cos L}{r^2}
=L_e(y)\frac{\rho}{\pi}V(x,y)\frac{4}{r^4}.
\]

先均匀选三盏灯，再均匀采灯面，所以q_A(y)=1/(3 A_light)。不同面积的灯PDF不同，不是所有面积样本都用相同常数。样本记录lightId和灯内归一化(u,v)，能重建固定灯面位置；重采样的是灯面点，不只是灯编号。

## 将BSDF与灯采样放到同一测度

余弦半球方向采样密度q_B,omega=cosX/pi。面积与立体角的关系：domega=cosL/r² dA。由同一事件的概率相等，q_B,A dA=q_B,omega domega，得到：

\[
q_{B,A}=q_{B,\omega}\frac{\cos L}{r^2}=\frac4{\pi r^4}.
\]

因此MIS可以在面积域比较q_A和q_B,A。每策略各取一个样本，Power权重w_L=q_A²/(q_A²+q_B,A²)，w_B=q_B,A²/(q_A²+q_B,A²)。两策略贡献相加，不再整体除2；每个策略内部已经除自己的采样PDF，MIS权重负责覆盖分配。

BSDF方向从余弦半球生成，和z=2平面求交后检查是否落在任一灯矩形。未命中灯返回零，仍计入样本数；命中时Lambert*cos/PDF抵消，未加MIS前贡献为rho*Le*V。板处于射线与灯之间，必须先验证无遮挡才能接受灯贡献。代码复用PT.6的PCG随机流和稳定Power权重函数，不复制一套不同定义的MIS。

参考：[PBRT面积灯与测度接口](https://pbr-book.org/4ed/Light_Sources/Area_Lights)。

## RIS选样与真实遮挡

对每个候选计算未遮挡贡献F0，目标取t=0.2126R+0.7152G+0.0722B。因为本场景灯都有正辐亮度、所有接收点朝向灯，真实非零贡献处t始终正。

生成8候选，按上一节的w=t/q_A更新Reservoir，最后只对选中的Y计算可见性：Lhat=V(x,Y)F0(Y) S/(8 t(Y))。目标只决定如何选择，最终可见性仍决定能量是否真的到达。

Visibility使用真实线段与板平面的交点：P(t)=x+t(y−x)，z分量为2t，令z=1解得t=1/2，所以交点xy是端点中点。检查是否落入板的矩形范围。当前固定平行平面的求交不需要经验epsilon；这不是通用三角网格鲁棒求交，也不宣称已接入DXR硬件。

游戏类比：先按未考虑墙壁的预计亮度挑灯，最后用阴影查询确认墙有没有挡住。不能因为前面评分高，就把这一步可见性结果省掉。

## 实现接口、布局与生命周期

共享几何位于`direct_scene.h`，关键接口：

```cpp
LightSample Draw(const Scene& s, mis::Rng& rng);
Evaluation Evaluate(const Scene& s, V3 x, LightSample y);
bool Visible(const Scene& s, V3 x, LightSample y);
V3 BsdfSample(const Scene& s, V3 x, mis::Rng& rng, bool useMis);
V3 Reference(const Scene& s, V3 x, unsigned resolution);
```

Scene拥有固定灯数组和板参数，const引用只借用；x必须位于z=0。Draw使用RNG引用推进随机流，返回按值样本；Evaluate返回未遮挡RGB、q_A、标量目标与q_B,A；Visible返回真实板遮挡结果；BsdfSample中的useMis决定是否应用Power权重；Reference用每个可见子矩形的resolution×resolution中点求积。

LightSample是uint32灯编号与两个double(u,v)，本机24B（含4B填充）；对应Reservoir为56B。它按值持有样本，不拥有几何，也不持有指针。样本由Draw或灯内求交生成，满足合法编号和[0,1]范围；Scene是受控解析场景，不是未验证外部资产接口。

宿主逐像素、逐试验计算，没有GPU资源或跨线程同步。Reservoir输入错误抛异常，主程序捕获并返回1；输出检查非负/有限、文件写入成功。构建沿用sm_120入口，但本节无CUDA kernel，不能报告GPU性能或声称GPU sanitizer覆盖了本程序。

## 参考值为何不直接用另一份随机图

独立面积求积不调用Evaluate或Visible，不复用蒙特卡洛候选。把板投影回灯面：灯面上的遮挡x区间为[2 bx0−x0,2 bx1−x0]，y同理。先把这些边界切入灯矩形，子矩形内部遮挡状态恒定，再对可见部分求积，避免中点网格跨过不连续阴影边界。

每点比较32与64分辨率求积；最大亮度差2.06106e-5。另对每场景四个点做256/512对照，最大亮度差3.06643e-7。这是参考稳定性证据，不是对所有输入的严格误差界。

每方法、每像素做4096次试验，种子20261021、每像素独立PCG流。比较逐RGB均值与参考，阈值为6个估计标准误差加4倍粗细参考差及1e-8。正确方法未出现超限；统计验证不代替无偏性推导。CSV里的mean_squared_mean_error是有限试验均值的误差平方平均，含残留采样误差，不能当成已证明的纯偏差平方。
