## 从要解决的问题推导beta

上一节BSDF射线打到非发光表面就没有直接光贡献，但该表面可能反射其他位置来的光。设相机首先看到x0，x0沿采样方向看到x1。我们要把x1的出射辐亮度传回x0朝相机的方向。

忽略介质、只考虑反射，在顶点xi写渲染方程：

\[
L_o(x_i,\omega_o)=L_e(x_i,\omega_o)+\int_{H_i}f_i(\omega_o,\omega) L_i(x_i,\omega)|n_i\cdot\omega|d\omega.
\]

沿方向ω无遮挡到达x(i+1)，真空中Li(xi,ω)=Lo(x(i+1),-ω)。用PDF pi采样方向，单样本估计为Le_i+Ai*下一顶点估计，Ai=fi*cos_i/pi。

展开：Le0+A0 Le1+A0 A1 Le2+…；由此定义beta0=1，beta(i+1)=beta_i Ai。抵达xi时beta_i只包含前i次散射，故该顶点自发光贡献为beta_i Le_i；当前fi尚未乘进去。

RGB beta逐分量相乘，不是三个通道取平均，也不是概率。它是蒙特卡洛路径权重，包含材料响应与采样密度补偿。对Lambert余弦采样它会化为反射率乘积，但对一般采样不成立。单个样本beta增长不等于能量不守恒，要看加权期望。

方向积分中的真空辐亮度沿射线保持不变，不应每段额外除距离平方。面积积分里的几何因子及前课面积PDF→立体角PDF转换已经体现距离；不能把面积形式和方向形式重复应用。

## Lambert的两个采样器

f=rho/pi，余弦采样p=cos/pi，故A=rho。均匀半球p=1/(2pi)，故A=2rho cos。后者E[cos]=1/2，仍有E[A]=rho，但每条路径的权重不同。例如rho=.6、cos=.9时A=1.08，合法且不违反能量守恒。

本课Sample返回世界方向wi、实际余弦、立体角PDF。各个球面位置法线不同，因此建立局部正交基：选择不近平行于n的辅助轴a，T=normalize(a×n)，B=n×T，wi=local.x*T+local.y*B+local.z*n。均匀采样z=u；余弦采样z=sqrt(1-u)；phi=2pi*v；横向半径sqrt(1-z²)。连续随机数在开区间，避免精确地平线。

## 更新顺序和深度约定

本课K是最多执行的表面散射数，不是命中次数。K=0仍可看见相机直接命中的自发光；K=1可访问两个表面、累加Le0+A0 Le1。

```cpp
RGB beta = {1,1,1}, L = {0,0,0};
for (int depth = 0; depth <= K; ++depth) {
    // 此时已经获得当前命中位置、材质和法线。
    L += beta * Le;
    if (depth == K) break;
    auto s = SampleBSDF(...);
    beta *= f * abs(dot(n, s.wi)) / s.pdf;
    // 生成下一条射线并查找下个交点。
}
```

以上为逐分量运算伪代码；实际std::array版本见path_loop.h。必须先累加当前发光，再判断是否还能散射。否则K=0连可见光源都被删掉。不能先乘当前rho再累加自发光，否则黑色反射材质的自发光也被错误删除。

发光表面也可以反射。仅当材质确实不散射或程序采用这种明确模型时，才可一命中灯就结束。上一节灯的反射率为0，而本课球腔每处既发光又反射，必须继续路径。

## 可解析的实验场景

封闭单位球，观察点在球心，初始方向+Z，首命中(0,0,1)。整个球的内表面均匀发光且Lambert反射，法线朝球心。rho=(.6,.4,.2)，Le=(.1,.2,.3)。没有NEE、介质、环境或透明；所有向内采样的方向都会击中另一处内表面。

对单位球面起点x和单位方向d，|x+td|²=1展开得t²+2t(x·d)=0。排除起点t=0，另一解t=-2x·d>0。计算后检查球面残差，再归一化交点消除double积累误差。这是已知起点在球面的专用求交，不能替代通用求交或鲁棒偏移。

均匀球腔的对称性使每个位置/出射方向辐亮度相同；Lambert半球积分∫cos dω=pi，所以稳态L=Le+rho L，逐通道解为L∞=Le/(1-rho)，要求0≤rho<1。

允许最多K次散射时：LK=Le∑(j=0..K)rho^j=Le(1-rho^(K+1))/(1-rho)。剩余尾项L∞-LK=Le*rho^(K+1)/(1-rho)。这是截断偏差，不会靠增加固定K的样本数消失。

余弦采样每步A=rho，此特殊场景每一条路径都得到解析有限和，数学方差为0。这不意味着余弦采样在一般场景无噪声；这里没有位置变化的材料/发光或可见性变化。均匀半球得到随机权重，均值仍对应同一有限和。

## 源码职责和接口

- `throughput_math.h:14`：Sample(normal,rng,cosineSampling)，normal是内向单位法线，rng按引用更新，布尔参数选两种采样器；返回世界方向/cos/PDF。零向量、非法半球方向抛异常。
- `throughput_math.h:26`：NextSphereHit(position,direction,distance,residual)，前两者为单位球面起点/单位方向，后两者按引用返回正距离和误差；非正距离或残差>1e-10失败。
- `path_loop.h:12`：Trace(rho,emission,maxScatters,mode,seed,stream)，RGB线性反射率和发光、最多散射次数、正常/故意错误模式、PCG种子和流编号。返回K+1个VertexRecord：抵达beta、当前贡献、累计L、散射后beta、cos/PDF/距离/残差。
- `throughput_test.cu`：8seed×8192路径，深度0..16，对照解析式并输出每深度统计及一条详细路径；SE用Welford统计8个seed均值，避免近零方差下二阶矩相消。

没有新平台API、GPU buffer或payload；所有状态为CPU局部值和vector，函数返回后由调用者持有。没有异步提交或Fence。文件创建、输入范围、几何、有限数值、解析比较失败均非零退出。本课沿用nvcc/sm_120构建，不代表执行过CUDA kernel或DXR。

## 如何接回PT.6的MIS

此参考实验只有BSDF延伸，没有额外NEE，因此每次命中发光用完整beta Le。接回双策略时，先在当前顶点计算beta_i乘以本地NEE估计（含灯策略MIS权重）；BSDF延伸更新beta后，抵达下一发光体再乘对应BSDF策略权重。该权重需要前一顶点和前次BSDF PDF。

一般不能把一次直接光的MIS权重乘进beta，再带到所有未来路径上：该权重在分配竞争的直接光连接，beta则携带已采样散射链的f*cos/pdf。相机直接看到的发光也不应误用上一跳PDF。下一小节接GPU循环时实现并验证这一状态区分。
